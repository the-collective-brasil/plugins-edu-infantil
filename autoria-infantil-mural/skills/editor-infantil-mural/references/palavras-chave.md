# Palavras-Chave da Jornada do Projeto · por nível

Lista travada · 29/09/2026 · Intercriativa Lab · Educação Infantil
Duas versões: Infantil 3 (13 palavras) e Infantil 4 e 5 (18 palavras). Não altere sem decisão
registrada.

## Como usar
- As palavras são apresentadas no Mural do Projeto, fase a fase, nos Cartões de Palavras-Chave
  da Jornada do Projeto.
- Escreva cada palavra e cada definição exatamente como estão aqui.
- A definição é a fala do educador para a criança.
- No Infantil 3, cada palavra vem com um gesto.

Fases: S1-S2 Imersão · S3-S4 Investigação · S5-S6 Criação · S7-S9 Experimentação · S10-S11
Apresentação · S12 Avaliação e Reflexão.

## Infantil 3 · 13 palavras

### Imersão
- Olhar: Olhar é usar os olhos para descobrir as coisas. (gesto: mãos em volta dos olhos, como binóculo)
- Sentir: Sentir é saber se estamos felizes, tristes ou com medo. (gesto: mão no peito)
- Escolher: Escolher é pegar uma coisa entre duas. (gesto: apontar para uma de duas opções)

### Investigação
- Perguntar: Perguntar é falar quando a gente quer saber uma coisa. (gesto: palmas para cima)
- Escutar: Escutar é usar os ouvidos para ouvir o amigo. (gesto: mão em concha na orelha)

### Criação
- Imaginar: Imaginar é pensar numa coisa de faz de conta. (gesto: dedo na cabeça, olhar para cima)
- Construir: Construir é juntar peças para fazer uma coisa nova. (gesto: punhos empilhados)

### Experimentação
- Experimentar: Experimentar é fazer para ver o que acontece. (gesto: mãos abertas, "vamos ver")
- Consertar: Consertar é mudar o que não deu certo. (gesto: fingir apertar um parafuso)

### Apresentação
- Mostrar: Mostrar é deixar os outros verem o que a gente fez. (gesto: mãos abertas, oferecendo)
- Contar: Contar é falar para os outros o que a gente fez. (gesto: mão saindo da boca)

### Avaliação e Reflexão
- Lembrar: Lembrar é pensar de novo no que a gente fez antes. (gesto: dedo na testa)
- Guardar: Guardar é colocar num lugar para não perder. (gesto: fingir colocar na pasta)

## Infantil 4 e 5 · 18 palavras

### Imersão
- Perceber: Perceber é prestar atenção no que acontece ao nosso redor.
- Sentir: Sentir é reconhecer como nós e os outros nos sentimos numa situação.
- Escolher: Escolher é decidir o que queremos conhecer melhor.

### Investigação
- Observar: Observar é olhar com calma para descobrir detalhes.
- Entrevistar: Entrevistar é fazer perguntas para uma pessoa e escutar as respostas.
- Pesquisar: Pesquisar é procurar respostas em livros, imagens e com as pessoas.

### Criação
- Imaginar: Imaginar é pensar em ideias novas que ainda não existem.
- Decidir: Decidir é escolher, junto com o grupo, qual ideia vamos fazer.
- Construir: Construir é fazer a primeira versão da nossa ideia com materiais.

### Experimentação
- Testar: Testar é usar o que fizemos para ver se funciona.
- Escutar: Escutar é ouvir o que os outros acham do que fizemos.
- Melhorar: Melhorar é mudar uma parte para funcionar do jeito que queremos.

### Apresentação
- Convidar: Convidar é chamar pessoas para ver e ouvir o que fizemos.
- Compartilhar: Compartilhar é mostrar para outras pessoas o que descobrimos e fizemos.
- Explicar: Explicar é contar como e por que fizemos cada parte.

### Avaliação e Reflexão
- Lembrar: Lembrar é contar como foi o projeto, do começo ao fim.
- Refletir: Refletir é pensar no que aprendemos e no que mudou.
- Registrar: Registrar é desenhar, escrever ou fotografar para não esquecer.
